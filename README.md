# OO Shop — Mobile Store

فروشگاه و پنل مدیریت تخصصی موبایل و لوازم جانبی با PHP و MySQL، طراحی RTL و پنل ادمین مبتنی بر UI تیره‌ی Stitch.

## قابلیت‌ها

- مدیریت محصولات، دسته‌بندی‌ها، برندها و تنوع‌های مدل/رنگ
- موجودی، انبارگردانی، لاگ تغییرات و هشدار کمبود موجودی
- سفارش‌ها، فروش حضوری، فاکتور و خروجی سفارش‌ها
- کوپن، پیشنهاد شگفت‌انگیز، بنر، دیدگاه و پیام‌های مشتری
- حسابداری، چک‌ها، سریال/IMEI و مدیریت اپراتورها
- CSRF، نشست امن، Prepared Statements و راه‌اندازی مدیر اولیه بدون رمز پیش‌فرض
- پنل RTL واکنش‌گرا با Dark/Light theme

## نیازمندی‌ها

- PHP 8.1+
- MySQL 5.7+ یا MariaDB 10.4+
- PDO MySQL
- Apache + mod_rewrite یا Nginx

## نصب

1. `config.example.php` را به `config.php` کپی کنید.
2. مشخصات دیتابیس را در `config.php` وارد کنید.
3. سایت را باز کنید تا ساختار دیتابیس ایجاد/ارتقا داده شود.
4. به `/admin/setup.php` بروید و مدیر اولیه را بسازید. Setup پس از ایجاد اولین مدیر خودکار غیرفعال می‌شود.
5. وارد `/admin/login.php` شوید.

> `config.php`، فایل‌های runtime، بکاپ‌ها و آپلود کاربران در Git ذخیره نمی‌شوند.

## ساختار

```text
admin/          پنل مدیریت
api/            endpointهای داخلی
assets/         CSS، JS، فونت و placeholder
uploads/        فایل‌های آپلودی runtime
data/           داده‌های runtime محافظت‌شده
schema.sql      ساختار دیتابیس و داده‌های پایه غیرحساس
config.example.php
```

## اصلاح پایداری محصولات

نسخه فعلی ذخیره محصول را به‌صورت تراکنشی انجام می‌دهد و پس از `UPDATE` مقدارهای اصلی را مجدداً از دیتابیس می‌خواند. Bootstrap دیتابیس دیگر محصولات، بنرها، نظرات، کوپن‌ها یا حساب مدیر حذف‌شده را seed نمی‌کند؛ در نتیجه داده‌ای که مدیر حذف یا ویرایش کرده در درخواست بعدی بازسازی نمی‌شود.

## امنیت

- هیچ حساب `admin/admin123` ساخته نمی‌شود.
- اولین مدیر فقط از صفحه one-time setup ایجاد می‌شود.
- رمزها با `password_hash()` ذخیره می‌شوند.
- فرم‌های مدیریتی دارای CSRF هستند.
- برای production حتماً HTTPS فعال باشد و `config.php` خارج از دسترس عمومی Git باقی بماند.

برای گزارش آسیب‌پذیری، اطلاعات حساس را در Issue عمومی قرار ندهید؛ `SECURITY.md` را ببینید.
